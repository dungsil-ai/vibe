# 대체어와 기술 범주

이 파일은 세 부분으로 되어 있다.

- 1부: 자주 쓰이는 비승인 단어의 대체어
- 2부: 기술 이름의 19개 범주
- 3부: 기술 동사의 4개 범주

## 1부: 자주 쓰이는 비승인 단어의 대체어

공식 사전은 비승인 단어마다 하나 이상의 승인 대체어를 제시한다. 아래 표에는 자주 쓰이는 대체어를 모았다.
대체어로 바꾼 뒤에도 문장의 뜻이 그대로 유지되어야 한다. 단어만 바꿔서 뜻이 달라지면 문장 구조를 바꾼다(규칙 9.1).

괄호 안의 설명은 그 단어를 어떤 뜻이나 품사로 쓸 때 대체어로 바꾸는지를 나타낸다.

| 비승인 단어 | 승인된 대체어 |
|---|---|
| about (대략이라는 뜻) | approximately |
| acceptable | permitted |
| accomplish, carry out, conduct, perform | do |
| activate | start, energize |
| additional | more |
| aid (동사) | help |
| assure, ensure, verify | make sure that |
| begin, commence, initiate | start |
| below (수치를 비교할 때) | less than |
| above (수치를 비교할 때) | more than |
| check (동사) | do a check of, examine, make sure that |
| damage (동사) | cause damage to |
| depending on | if, as a function of |
| detect (절차 글에서) | find |
| determine | calculate, find |
| enough | sufficient |
| exactly | accurately |
| extend to | be applicable to |
| finish | complete, stop |
| follow (지시나 규칙을 따른다는 뜻) | obey |
| following (형용사) | that follows |
| give off | release |
| goes down | decreases |
| goes up | increases |
| help (명사) | aid |
| however | but |
| in order to | to |
| just (오직이라는 뜻) | only |
| main | primary |
| maintain | keep, hold |
| may, might | can |
| observe (본다는 뜻) | look at, examine |
| obtain | get |
| put out (불을 끈다는 뜻) | extinguish |
| prior to | before |
| require | be necessary, must |
| see (확인한다는 뜻) | make sure that |
| shall, should | must |
| simultaneously | at the same time |
| technique | method |
| test (동사) | do a test of |
| turn (상태가 바뀐다는 뜻) | become, change to |
| use up | use all of |
| utilize | use |
| wear (동사) | put on, use |
| whilst | while |
| within | in |
| would | will, can으로 바꾸거나 삭제 |

참고: 대체어의 최종 기준은 공식 사전이다. 공식 규격을 가지고 있다면 그 규격의 ALTERNATIVES 열을 쓴다.

## 2부: 기술 이름의 19개 범주 (규칙 1.5)

아래 범주 가운데 하나에 속하는 단어는 명사나 형용사로 쓸 수 있다.

1. 공식 부품 정보에 있는 이름. 예: bolt, filter, switch
2. 차량이나 기계의 이름과, 차량이나 기계에서 위치를 가리키는 이름. 예: aircraft, cabin, wing
3. 공구와 지원 장비의 이름. 예: clamp, gauge, torque wrench
4. 재료, 소모품, 불필요한 물질의 이름. 예: grease, sealant, dust
5. 시설과 기반 시설의 이름. 예: hangar, dock, building
6. 시스템, 구성품, 회로와 그 기능의 이름. 예: pump, latch, standby mode
7. 수학, 과학, 공학 용어. 예: diameter, voltage, torque
8. 항법과 지리 용어. 예: altitude, north, France
9. 숫자, 측정 단위, 시간. 예: 92, kilogram, winter
10. 명판, 라벨, 표지판, 화면에서 인용한 글. 예: the EXIT sign, the ON position
11. 사람, 집단, 조직의 이름. 예: captain, crew, manufacturer, FAA
12. 신체 부위. 예: hand, eyes, skin
13. 일반적인 개인 소지품. 예: clothing, footwear, matches
14. 의학 용어. 예: allergy, dizziness, headache
15. 공식 문서와 문서 구성 요소의 이름. 예: chapter, figure, Service Bulletin
16. 환경 조건과 운용 조건. 예: rain, ice, turbulence
17. 색. 예: red, orange, magenta
18. 손상 용어. 예: crack, corrosion, dent
19. 정보 기술과 전화 통신 용어. 예: database, cursor, laptop, e-mail, file

기술 이름에는 다음 규칙을 적용한다.

- 기술 이름을 동사로 쓰지 않는다(규칙 1.7).
- 프로젝트의 공식 명명 체계를 따른다(규칙 1.8).
- 한 대상에는 이름을 하나만 쓴다(규칙 1.11).
- 속어나 은어를 쓰지 않는다(규칙 1.10).

## 3부: 기술 동사의 4개 범주 (규칙 1.12)

아래 범주 가운데 하나에 속하는 동사는 승인 동사로 뜻을 충분히 나타낼 수 없을 때 쓸 수 있다.

1. 제조 공정. 예: drill, ream, rivet, weld, solder, anneal, polish, cast
2. 컴퓨터 처리와 응용 프로그램. 예: click, copy, paste, delete, save, scroll, download, install, reboot
3. 설명 동사. 설명 글에서만 쓰고, 절차 글에서는 쓰지 않는다. 예: detect, emit, radiate, comply with, supersede
4. 운용 동사. 운용 맥락에서만 쓴다. 예: fly, land, taxi, navigate, hover, brief

기술 동사에는 다음 규칙을 적용한다.

- 쓸 수 있는 승인 동사가 있으면 승인 동사를 쓴다. 절차 글에서는 `detect`가 아니라 `find`로 쓴다.
- 기술 동사를 명사로 쓰지 않는다(규칙 1.13).
- 기술 동사의 과거분사는 형용사로 쓸 수 있다. 예: `the reamed hole`
