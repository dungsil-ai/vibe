# 바이브 핸드오프

지금까지의 대화를 요약한 핸드오프 문서를 작성해 새 에이전트가 작업을 이어갈 수 있게 한다. 요청을 받은 작업 공간이 아닌 사용자 OS의 임시 디렉터리에 저장한다.

문서에 "제안 스킬" 섹션을 포함하고, 에이전트가 호출해야 할 스킬을 추천한다.

아키텍처 결정 기록(Architecture Decision Record, ADR)을 비롯해 명세, 계획, 이슈, 커밋, diff를 다른 산출물로 다룬다. 다른 산출물에 이미 담긴 내용은 복제하지 않는다. 대신 경로나 URL로 참조한다.

API 키, 비밀번호, 개인 식별 정보 같은 민감 정보는 모두 가린다.

사용자가 인자를 전달했다면, 그 인자를 다음 세션이 집중할 내용으로 보고 문서에 반영한다.
