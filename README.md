# DUNGSIL's Vibe Skills

바이브 코딩용 [에이전트 스킬](https://agentskills.io/home) 모음집

## 설치

스킬이 올바르게 작동하기 위해서 모든 스킬을 받아야 합니다.

```
pnpm dlx skills add dungsil-ai/vibe -g -y --skill *
```
